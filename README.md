<h1 align="left">Poll App</h1>

###

<p align="left">PollApp is an Angular, TypeScript and SCSS app for creating, sharing, and analyzing surveys in real time. Supabase was used as the backend for authentication and data storage.<br>

This app is part of the Developer Akademie's training programme for software developers (www.developerakademie.com). 
<br><br>

## Setup & Quickstart

**1. Clone the repository**
```bash
   git clone https://github.com/karinaklages/poll-app.git
   cd poll-app/poll-app
```

**2. Install dependencies**
```bash
   npm install
```

**3. Start the development server**
```bash
   ng serve
```
   Open [http://localhost:4200](http://localhost:4200) in your browser.

**4. Build for production**
```bash
   ng build --base-href "/angular-projects/poll-app/"
```
